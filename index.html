تست DNS از دید کاربر (DoH)

بدون سرور • درخواست‌ها از IP خودِ کاربر ارسال می‌شود
تنظیمات DNS-over-HTTPS
اگر “Custom” انتخاب کنی، باید **آدرس DoH** (نه IP خام) بدی. بیشتر DNSها IP-only توی مرورگر قابل تست نیستن.
برای مقایسه، یک DNS دوم هم می‌تونی تست کنی.
برای کاهش خطاهای لحظه‌ای شبکه، ۲ بار مناسب‌تره.
اگر اینترنت ضعیف باشه، مقدار رو مثلاً 5000 بذار.
آماده
نتیجه‌ها از شبکه‌ی خودت (اینترنت/اپراتور) گرفته می‌شن.
این تست “Resolve” رو با DoH انجام می‌ده، نه Ping واقعی. زمان‌ها، مدت پاسخ HTTP+DNS هستند.
راهنما چرا نتایج قبلی غلط بود؟
نسخه‌ی قبلی، DNS Resolve رو روی سرور Vercel انجام می‌داد؛ یعنی نتیجه‌ها از دید شبکه‌ی Vercel بود. این نسخه درخواست‌ها رو مستقیم از مرورگر تو می‌زنه، پس برای موبایل/اپراتور/وای‌فای تو واقعی‌تره.
اگر بخوای “IP خام DNS” رو دقیق تست کنی (UDP/TCP پورت 53)، باید اپ/کلاینت داشته باشی؛ مرورگر اجازه نمی‌ده.
