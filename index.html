Game Renter

تست DNS برای Xbox / PlayStation + داخلی/بین‌المللی
اگر فقط یکی وارد شود، همان تست می‌شود. اگر هر دو وارد شوند، هر دو DNS به‌صورت جداگانه بررسی می‌شوند.
این تست فقط بررسی می‌کند DNS بتواند دامنه‌های کلیدی هر سرویس را Resolve کند. نتیجه نهایی ممکن است به ISP/منطقه هم وابسته باشد.
